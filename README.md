# 赛博霓虹 Warmpix Neon

霓虹灯管、灯带、摇头灯、激光、迪斯科球、全息投影，用 16 通道控制台统一调色和编排灯光。

- Minecraft：26.3
- 加载器：NeoForge 26.3.0.23-beta 或更高
- 客户端与服务端都需要安装
- 无其他模组前置
- 语言：简体中文 / English

## 下载

请到 [Releases](../../releases) 页面下载 jar（版本 1.0.4）。

## 内容

- 灯具：霓虹灯管、LED 灯带、发光面板、霓虹玻璃、舞池地板、赛博壁灯、光环吊灯、霓虹立灯、摇头聚光灯、激光投射器、迪斯科球、霓虹招牌、全息投影仪、隐形光源、烟雾机
- 单盏灯可调亮度、发光强度、主副色和效果（呼吸、闪光、同步变色、彩虹流动、追光、往返、故障闪断、星闪、按 BPM 打拍等）
- 摇头灯与激光可调运动方式、水平角、俯仰角、光束长度宽度、光束数量与扇面角度；招牌和全息可显示自定义文字
- 灯光控制台：16 个可命名通道、总开关、TAP 打拍、场景保存与调用；灯光链接器可框选批量链接（每边最多 48 格）；灯光遥控器远程控制
- 调色工具：吸取一盏灯的颜色和效果，刷到其他灯上
- 赛博建材：镜面地砖、光栅地板、赛博墙板、碳纤维板、金属格栅、电路板方块、服务器机柜、六边形强化玻璃、背光酒架、霓虹吧台与吧凳
- 四款鸡尾酒和四色荧光棒
- 全部贴图带 labPBR 法线/高光贴图，适配 Iris 光影；/neonfx 切换原版光晕或光影模式
